# Prioritiser

A native macOS todo app that helps you decide **what to do next** — not just what's
on your plate. Tasks carry impact, priority, effort, and due dates; an auto-computed
score ranks them into a "Top 5 now" list. Built in SwiftUI from a Claude Design
prototype.

## Status

**Slices 1–3 complete.** The three-pane app runs against a seeded SQLite store: a
translucent sidebar (smart views + Finder-style folder tree), the task list (with
the auto-ranked Top-5 band), and an always-on detail inspector (score breakdown +
editable impact/priority/state). Quick-add parses the prefix grammar as you type
and shows live preview chips, and **⌘N** opens a Spotlight-style capture. A toolbar
**Tweaks** popover (and the Settings ⌘, window) controls appearance (System/Light/
Dark), accent color, and priority visualization (cards/bars/heat). See
[`plans/prioritiser-macos-implementation.md`](plans/prioritiser-macos-implementation.md)
for the full roadmap and [`changelog.md`](changelog.md) for what's landed.

Later slices add: full detail/notes/folder editing, and a Swift 6 concurrency
hardening pass.

## Requirements

- macOS 14.0+
- Xcode 26 (Swift toolchain), [xcodegen](https://github.com/yonomi/xcodegen)

## Build & run

```sh
make setup    # install xcodegen if needed + generate Prioritiser.xcodeproj
make build    # compile the app
make run      # build then launch
make test     # run the unit test suite
```

The Xcode project is generated by `project.yml` (xcodegen) and is **not** committed —
run `make setup` after cloning.

## Architecture

Clean layers under `Sources/`:

| Layer | Responsibility |
|-------|----------------|
| `Models/` | `TaskItem`, `Folder`, `Level`, `TaskState`, `SmartView`, `Selection` |
| `Domain/` | Pure logic: `PriorityScorer`, `PrefixParser`, `TaskFilter`, `Formatting`, `FolderTree`, `TaskClock` |
| `Data/` | SQLite (`Database`), versioned `Migrations`, `TaskStore` repository, `SeedData` |
| `Theme/` | `OKLCH`→sRGB conversion, accent + chip `Palette`, `NSVisualEffectView` bridge |
| `Features/` | SwiftUI panes: `Sidebar`, `TaskList`, `Detail`, `QuickAdd`, shared `UIAtoms` |
| `App/` | `PrioritiserApp` entry point, `AppModel` observable state, `ContentView` |

The domain layer is pure and clock-injectable, so scoring/parsing/filtering are
unit-tested deterministically (`Tests/PrioritiserTests/`).

## The priority score

```
score = 0.30·impact + 0.25·priority + 0.30·urgency + 0.15·quickWin   (×100)
```

- impact/priority ∈ {low, medium, high} → {1, 2, 3} ÷ 3
- urgency: overdue/today → 1; falls off linearly to 14 days out; no due date → 0.25
- quick-win: shorter effort scores higher (`1 − log₁₀(1 + minutes/10) / 2`)

## Quick-add grammar

Type prefixes to capture context inline:

| Prefix | Meaning | Example |
|--------|---------|---------|
| `#folder` | file under a project | `#prioritiser` |
| `due:` | due date | `due:tomorrow`, `due:15 May 2026`, `due:2026-05-15` |
| `t:` | effort (m/h/d, day = 8h) | `t:10m`, `t:1h`, `t:3d` |
| `i:` | impact (h/m/l) | `i:h` |
| `p:` | priority (h/m/l) | `p:l` |
